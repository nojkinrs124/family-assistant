# План по этапам

## Этап 1 — фундамент ✅ (в этом репозитории)

- [x] Supabase: `families`, `profiles`, `family_members`, `settings`, `audit_logs`, RLS по `family_id`
- [x] Telegram `/start`: создание профиля по `telegram_id`, автосоздание семьи с ролью owner
- [x] `audit_logs` пишется при сборке корзины

Не сделано осознанно (не нужно для Этапа 1):
- Приглашение других участников семьи (добавление `family_members` вручную/по инвайт-ссылке) — потребуется, когда в семье появится второй пользователь
- UI ролей/permissions за пределами `owner` — таблица и enum уже готовы, интерфейса управления пока нет

## Этап 2 — покупки (частично, прототип)

- [x] MCP-сервер Ленты: `lenta_search`, `lenta_cart_add`, `lenta_checkout_link`
- [x] Shopping Agent в боте: разбирает запрос, вызывает тулы, отдаёт ссылку на чекаут
- [ ] **Блокер**: селекторы в `lenta-mcp/src/tools/*.js` — заготовки, не откалиброваны под реальную вёрстку сайта. Без этого шага автоматизация не заработает физически.
- [ ] Таблицы `shopping_lists`, `shopping_list_items`, `orders`, `order_items`, `stores` — ещё не созданы (сейчас заказ нигде не сохраняется, только уходит в `audit_logs` как факт запроса)
- [ ] Проверка экрана оплаты (один клик vs SMS/3-D Secure) — определит, может ли `lenta_checkout_link` в будущем расшириться до автооплаты, или оплата навсегда остаётся ручной

## Этап 3 — финансы (не начат)

`accounts`, `transactions`, `categories`, `budgets`, `savings_goals`.
Связка `order → transaction` возможна только после того, как в Этапе 2
появится таблица `orders` с реальной суммой заказа.

## Этап 4 — оплата (не начат, осознанно)

Требует выбора платёжного провайдера с эквайрингом (ЮKassa/CloudPayments
и т.п.) — сохранённая в аккаунте магазина карта для ручной оплаты не
равна автосписанию через бота. Пока не решено — оплата остаётся ручным
шагом пользователя, это не костыль, а осознанная граница безопасности.

## Этап 5 — AI-ассистент верхнего уровня (не начат)

Вопросы вида «сколько потратили на продукты в этом месяце» — возможны
только после Этапа 3.

## Следующий конкретный шаг

1. Откалибровать селекторы `lenta-mcp` под реальную вёрстку (через DevTools или Claude в Chrome)
2. Прогнать `npm run auth` → `lenta_search` → `lenta_cart_add` → `lenta_checkout_link` вручную, проверить, что ссылка на чекаут реально открывается и сумма верна
3. Только после этого — таблицы `shopping_lists`/`orders` и запись реального заказа в БД
